## 2. 优先精读的社招问题链

### S1：个人项目是不是真能用

N02问“谁在用、效果怎样、为什么要做”；N104/N120反映岗位名相近但业务、资历或表达不匹配。MemOS应展示一条跨会话约束任务，不只展示接口返回200或测试数量。纯后端简历保留真实业务经历为主，AI版突出可验证治理和评测，不虚构用户或独立开发比例。[两年Java社招](https://www.nowcoder.com/discuss/914627656245600256)、[转型复盘](https://www.nowcoder.com/discuss/917172977467162624)。

### S2：可靠性问题会沿传统后端继续追问

N101问重复执行、沙箱登录态、权限、超时、压测与AB验证，还追问线程池、GC和数据库。N110问provider抽象、错误分类、限流和成本，N97关心SLA和故障响应。对应MemOS的Outbox、fence、API身份、provider边界与分阶段指标；不能因此声称自己有这些公司的生产规模。[字节社招全流程](https://www.nowcoder.com/feed/main/detail/8f3bfc31861346c5a71776abc0da9396)、[晓多社招](https://www.nowcoder.com/feed/main/detail/46fb9f8bb8434687921f5363fe1db94f)。

### S3：前沿不是换名词，而是问上下文和治理

N119追问案例污染、日志压缩、Skill固定合同与动态参数、混合检索和长期知识选择；N103问知识泄露、流式结构化输出和压缩恢复；N105問更新知识、权限与崩溃恢复。这些可以转成明确失败用例，但作者参考回答要另行核验。[9月社招面经](https://www.nowcoder.com/discuss/926232883432296448)、[拼多多复活赛](https://www.nowcoder.com/feed/main/detail/2109cf8eb0254507911fbf86bcbf51e4)、[深信服社招](https://www.nowcoder.com/feed/main/detail/45b40914f438434b88b60a21e3d5ec1e)。

### S4：AI Coding 要证明交付责任

N88追问多Agent是否必要、并发修改冲突、SDD/TDD和端到端门禁；N108进一步区分一次通过与人工介入后的成功。MemOS需要展示个人能解释的反例、代码与测试，不能把AI生成代码占比当提效指标。[基元律动](https://www.nowcoder.com/feed/main/detail/64e31a28581b4e21a1e8e1aee236b6b4)、[顺丰二面](https://www.nowcoder.com/feed/main/detail/93a26b84a6634558b7228bf350c709b5)。

## 5. 技术校准：题目不是答案

LangGraph当前官方材料区分thread checkpointer和跨thread store；它们不是同一种记忆。MCP授权规范讨论HTTP传输层认证授权流程，不替代业务对象权限，也不意味着MemOS已实现MCP。pgvector官方材料要核对过滤和索引行为后才用于选型，不能照面经默认“向量越多必然越慢”。[LangGraph](https://docs.langchain.com/oss/python/langgraph/persistence)、[MCP授权规范](https://modelcontextprotocol.io/specification/2025-11-25/basic/authorization)、[pgvector](https://github.com/pgvector/pgvector)。

本轮导学明确：当前lexical通道不直接宣称BM25；RRF分数不是概率；引用枚举不等于支持关系；本地trace字段不等于完整分布式可观测；政策拒绝不等于入口DLP。框架文档可能更新，规范链接按版本引用，生产集成应再核对部署版本。
